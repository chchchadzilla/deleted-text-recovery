Don't panic. Your text may still be on this computer.

When you type into a web page, your browser quietly keeps copies so it can restore your tabs after a crash. Those copies often survive a wrong click, a reload, or a message that sent blank. This tool finds them.

Before anything else

  1. Leave the tab where you lost it open. Don't close it and don't reload it.
  2. Don't restart the computer.
  3. Do as little as you can in that browser. It clears old copies away as you keep browsing, sometimes within an hour or two.
Four things to try first (20 seconds)
  1. Click inside the box you were typing in and press Ctrl + Z a few times (Command + Z on a Mac).
  2. If the page changed, press the browser's Back button once. Browsers often put your text back.
  3. If you closed the tab, press Ctrl + Shift + T (Command + Shift + T on a Mac) to reopen it.
  4. On Windows, press Windows + V. If you ever copied the text, it may be in that list.

No luck? Carry on below.

    What I found

    Nothing matches yet. Things that often help:

    • Clear the search box, or set "Shortest to show" to "anything".
    • Set "Look back" to "as far as possible" and scan again.
    • On Windows, close every window of the browser you were typing in (do not reopen it) and scan again. A running browser keeps its newest history file locked.
    • Drop the folder of a different browser or profile. Each one keeps its own history.
    • Try the desktop app. It checks every browser and writing app on the computer by itself.

    Some text cannot be recovered: rich editors (the kind with bold and italic buttons) and pages that switch autosave off leave fewer traces. It was still worth looking.

    Got it back? Copy it somewhere safe first. Then, if this saved your work, give the project a star on GitHub so the next person in a panic can find it.

    Is this safe? What does it read?

    This page has no way to send your data anywhere. It is built with a security rule (a Content-Security-Policy) that blocks it from making any network connection at all. You can turn your internet off after the page has loaded and it will work the same.

    The app runs on this computer only, at the address 127.0.0.1, which other devices cannot reach. It makes no network connections.

    It reads the autosave history of browsers and writing apps: tab-restore files, the small databases websites keep, and unsaved-document backups. It opens them read-only and changes nothing.

    It never opens saved passwords, cookies, payment details or encryption keys. Those files are on a block list in the code.

    Everything it finds stays in this tab's memory and is gone when you close it. Nothing is saved unless you press "Save as a text file".
