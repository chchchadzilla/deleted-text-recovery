**Typed it. Lost it. Get it back.**

Deleted Text Recovery finds text you typed and then lost: a forum reply, an essay, a long comment, a prompt. It reads the autosave trails your browser and apps already keep on your own computer. Free, no ads, no account, and nothing is uploaded.

## If you just lost something

1. Leave the tab open. Don't reload it. Don't restart your computer.
2. **Windows:** download `DeletedTextRecovery-Windows.exe` below, open it, choose "More info" then "Run anyway" if Windows asks, and press **Scan this computer**.
3. **Mac, Linux, or if you would rather not download anything:** open the web app at <https://chchchadzilla.github.io/deleted-text-recovery/> and follow its three steps.

Full, friendly instructions are in the [README](https://github.com/chchchadzilla/deleted-text-recovery#readme).

## What is in this release

- Recovers the contents of text boxes from the tab-restore history of Chrome, Edge, Brave, Vivaldi, Opera, Arc, Chromium and Firefox, with the full history of saved copies.
- Searches drafts that websites and extensions keep in browser storage.
- Searches unsaved-file backups from VS Code-family editors, Notepad++, Windows Notepad and Microsoft Office.
- Finds other apps built on Chromium (Slack, Discord, Notion and many more) by itself.
- A web app that works entirely inside your browser tab, and a desktop app with a one-button screen and a command-line mode.

## Downloads

| File | For |
| --- | --- |
| `DeletedTextRecovery-Windows.exe` | Windows 10 and 11 (64-bit) |
| `DeletedTextRecovery-macOS-AppleSilicon.tar.gz` | Macs with an M-series chip |
| `DeletedTextRecovery-macOS-Intel.tar.gz` | Older Intel Macs |
| `DeletedTextRecovery-Linux-x64.tar.gz` | Linux on Intel or AMD |
| `DeletedTextRecovery-Linux-arm64.tar.gz` | Linux on ARM |
| `deleted-text-recovery.cjs` | Any system with Node.js 20 or newer: `node deleted-text-recovery.cjs` |
| `DeletedTextRecovery-WebApp.html` | The web app as a single file |
| `SHA256SUMS.txt` | Checksums for every file above |

The programs are not code-signed yet, so Windows and macOS will warn about an unknown developer. The web app needs no download at all.

## Honest status

- Tried on real lost text on Windows 11 with Chrome, Edge and Brave.
- macOS and Linux pass the automated tests but have not yet had a confirmed real-world recovery. Firefox support is tested on made-up files only.
- If you try it on a Mac, on Linux or with Firefox, please [say how it went](https://github.com/chchchadzilla/deleted-text-recovery/discussions).
